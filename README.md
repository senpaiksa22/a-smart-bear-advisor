## 🌍 نظرة عامة | Overview

### [العربية]
**مستشار الدب الذكي** هي منصة استراتيجية ومعرفية متقدمة مبنية بنسبة 100% على فكر وتجارب رائد الأعمال الشهير **جيسون كوهين (Jason Cohen)**، مؤسس شركة اليونيكورن **WP Engine** و **Smart Bear Software**.  
تضم المنصة **213 مقالاً استراتيجياً كاملاً** مترجمة ومدققة باللغتين العربية والإنجليزية، ومصنفة خوارزمياً إلى **14 محوراً عضوياً حراً** تمثل دورة حياة الشركات الناشئة من الفكرة والتمويل الذاتي (Bootstrapping) وحتى التوسع والمنافسة وملاءمة المنتج للسوق (PMF).  
تتضمن المنصة أيضاً **مستشار ذكاء اصطناعي تفاعلي** يتقمص فكر جيسون كوهين بنماذج متعددة، وخريطة فكر هندسية تفاعلية، ونظام مفضلة حصري للأعضاء، مع أمان مشدد وتكلفة تشغيلية قدرها **0 دولار للأبد ($0 Forever)**.

### [English]
**A Smart Bear Advisor** is an executive-grade knowledge engine and interactive AI advisor built upon the collective essays, mental models, and frameworks of **Jason Cohen** (Founder of WP Engine and Smart Bear Software).  
The platform indexes **213 complete long-form essays**, fully bilingual (English & Arabic), organically clustered into **14 tactical themes** spanning bootstrapping, pricing power, PMF, moats, and startup strategy.  
It features an **interactive visual Mind Map** (Cards & Compact strips), an **AI Advisor simulating Jason Cohen** powered by Google Gemini, a **Members-Only Bookmarks system**, deep SEO optimization, and an enterprise-grade security architecture designed to run **100% Free Forever ($0 Cost)**.

## 🛠️ المعمارية التقنية والتكلفة الصفرية | Zero-Cost Architecture ($0)

تم تصميم النظام بالكامل ليعمل على بنية تحتية مجانية مدى الحياة بدون الحاجة لأي بطاقة ائتمانية:

- **الواجهة والخادم (Frontend & Backend):** Next.js 16 (App Router) + React 19 + Tailwind CSS على منصة **Vercel** (مجاني للأبد).
- **الذكاء الاصطناعي (AI Inference):** Google AI Studio (**Gemini 1.5/2.0 Flash**) — باقة مجانية تتيح 1,500 طلب يومياً مجاناً ($0).
- **قاعدة البيانات والتوثيق (Database & Auth):** **Supabase PostgreSQL** — باقة مجانية تدعم حتى 50,000 مستخدم نشط شهرياً ($0). مع توفر نظام تخزين محلي JSON تلقائي للطوارئ.
- **إدارة الجلسات:** JSON Web Tokens (JWT) مشفرة داخل ملفات تعريف ارتباط `HttpOnly` آمنة مع حماية CSRF/XSS.

## 🚀 دليل التشغيل المحلي | Local Development Setup

### 1. استنساخ المشروع وتثبيت الحزم
```bash
git clone https://github.com/senpaiksa22/a-smart-bear-advisor.git
cd a-smart-bear-advisor
npm install
```

### 2. إعداد متغيرات البيئة (`.env.local`)
انسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```
ثم ضع مفاتيحك الخاصة:
```env
# Google Gemini API Key (مجاني من aistudio.google.com)
GEMINI_API_KEY=AIzaSy...

# Supabase (اختياري - يوجد نظام تخزين محلي تلقائي إذا لم يتم تعيينهما)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...

# JWT Secret لتشفير الجلسات (أي نص عشوائي قوي بطول 32 حرفاً فأكثر)
JWT_SECRET=super_secret_jwt_random_string_change_in_production_32chars
```

### 3. تشغيل الخادم المحلي
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🌐 خطوات النشر السحابي (Supabase + Vercel)

### أولاً: إعداد Supabase (قاعدة البيانات السحابية المجانية)
1. افتح [Supabase.com](https://supabase.com/) وسجل حساباً مجانياً (باستخدام GitHub).
2. أنشئ مشروعاً جديداً **New Project** واختر اسماً وكلمة مرور لقاعدة البيانات.
3. من القائمة الجانبية، ادخل على **SQL Editor**، واضغط **New query**.
4. انسخ كود ملف `supabase/schema.sql` والصقه هناك ثم اضغط **Run**.
5. اذهب إلى **Project Settings > API** وانسخ:
   - `Project URL`
   - `service_role secret` (احفظه في سرية تامة).

### ثانياً: النشر على Vercel (خلال دقيقة واحدة)
1. افتح [Vercel.com](https://vercel.com/) وسجل الدخول بحساب GitHub.
2. اضغط على **Add New Project** واختر مستودع `a-smart-bear-advisor`.
3. في قسم **Environment Variables**، أضف المتغيرات التالية:
   - `GEMINI_API_KEY`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `JWT_SECRET`
4. اضغط **Deploy**. مبارك! موقعك الآن متاح برابط عالمي سريع وآمن ومجاني للأبد.
